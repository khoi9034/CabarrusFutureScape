# CFS Economics Power BI Starter Pack

## Download

Open Economics, then Power BI & Tools, then select **Download Starter Pack**.

- Demo: sanitized package labeled `Portfolio demonstration data`
- Local Live: package generated by FastAPI from local API/PostGIS economics data

The ZIP contains seven CSV tables, `model.json`, `data_dictionary.csv`,
`relationships.json`, `provenance.json`, Power Query M templates, DAX measures,
a report guide, an import QA checklist, and this workflow in `README.md`.

## Model

| Table | Grain | Primary key/use |
| --- | --- | --- |
| `economics_kpi_fact` | One current KPI | `kpi_id`; executive cards |
| `parcel_economic_signal_fact` | One screening signal | `signal_id`; parcel/site comparison |
| `scenario_output_fact` | One scenario output | `scenario_id`; scenario matrix |
| `domain_readiness_dim` | One readiness domain | `domain_id`; confidence register |
| `geography_dim` | One screening geography | `geography_label`; geography slicer |
| `time_dim` | One extract period | `year`; freshness label |
| `scenario_dim` | One scenario | `scenario_id`; scenario slicer |

Relationships are many-to-one, active, and single direction:

- `scenario_output_fact.scenario_id` to `scenario_dim.scenario_id`
- `parcel_economic_signal_fact.geography_label` to
  `geography_dim.geography_label`

Scenario and parcel facts remain disconnected because no validated scenario to
parcel business key exists.

## Measures

The included DAX references exported fields and provides Total Signals,
Underbuilt Candidates, Data Needed Signals, Scenario Count, Strong Fiscal
Scenarios, Average Revenue Per Acre, and Median Improvement-to-Land Ratio.
Blank numeric values remain blank.

## QA and safe use

Run `npm run check:powerbi`. It verifies files, headers, nonempty tables,
provenance, row counts, relationships, forbidden private fields, DAX/M
references, ZIP contents, and visible local/demo downloads.

Compare value per acre only within similar economic segments. The package is
screening-level context, not an appraisal, tax bill, fiscal impact study, or
development recommendation.
