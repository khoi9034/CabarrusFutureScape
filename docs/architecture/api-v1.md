# CFS API V1

## Compatibility

Existing unversioned routes remain available. Product V1 adds `/api/v1`
compatibility for health, parcels, planning, economics, investments, projects,
snapshots, scenarios, reports, Ask CFS, data sources, ingestion, artifacts, and
audit. Versioned routers call existing domain services rather than duplicate them.

## Common response behavior

- `X-Request-ID` is accepted when valid or generated by the API and returned.
- Timestamps are timezone-aware UTC ISO 8601 values.
- Mutations identify the authenticated principal and produce audit history.
- Raw database tables and unrestricted SQL are never exposed.
- Provenance remains attached to analytical evidence and exports.

## Error envelope

Product V1 errors use a stable shape:

```json
{
  "error": {
    "code": "conflict",
    "message": "The record changed before this update.",
    "request_id": "request-id",
    "details": []
  }
}
```

Messages are safe for clients. Stack traces, SQL text, secrets, tokens, and
private provider errors are not returned. Validation errors use `422`, missing
objects `404`, authorization `401/403`, conflicts `409`, and unavailable
dependencies `503`.

## Collections

Collection endpoints use bounded `limit` and `offset`, stable ordering, explicit
allowlisted sort fields, and typed filters. A response includes total count and
the applied paging/sort context where the existing domain contract permits.
Client-supplied SQL fragments or column names are never accepted.

## Conflicts and versions

Mutable records expose an update timestamp or version. Stale writes return a
conflict rather than overwriting newer work. Snapshot/scenario versions and audit
events are append-only.

## OpenAPI

FastAPI generates OpenAPI from typed request/response models. `check:api-contracts`
verifies required paths, common headers/errors, pagination bounds, authorization,
and that legacy routes remain present.

## Status

The contract is Product V1 scope. Check results are recorded in the implementation
report, not inferred from this document.
